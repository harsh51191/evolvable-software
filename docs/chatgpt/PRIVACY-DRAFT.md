# EVOLVE privacy notice — draft for publisher review

This notice concerns the skills-only EVOLVE plugin published by Vellanki Sriharsha. The package contains instructions, references and Python scoring scripts. It includes no publisher-operated MCP server, telemetry or analytics. The bundled scoring scripts use Python's standard library and do not make network calls.

When used inside ChatGPT or another agent host, repositories, uploaded files, prompts, generated reports and assessment inputs are processed using that host and any tools the user authorizes. Host-provider policies govern their processing, retention and deletion; the absence of plugin telemetry does not mean that no data leaves the user's device. EVOLVE does not supply a separate publisher backend for uploading assessment data.

Repository access depends on the host's available tools and permissions. Assessment files are written in the host execution environment. Never include credentials or confidential excerpts in public reports.

Support through GitHub issues is public. Information voluntarily posted there is visible to others and governed by GitHub's policies. This draft does not promise deletion of public copies or define an unconfirmed publisher retention policy.

Before publication, the publisher must confirm that these statements describe actual deployment and support practices, and resolve contact, retention/deletion handling and any additional data practices. This draft is not a finalized public policy.
