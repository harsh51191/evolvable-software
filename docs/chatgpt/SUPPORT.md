# EVOLVE support

Publisher: Vellanki Sriharsha. EVOLVE is free, open-source software.

For questions, bugs or factual corrections, open an issue at https://github.com/harsh51191/evolvable-software/issues . Include the plugin version, steps to reproduce, and a minimal sanitized example. Do not post private source code, credentials, personal data or customer information: repository issues are public. Support is community-based; no response-time guarantee is offered.
