# EVOLVE privacy notice

Effective date: 3 October 2026. Publisher: Vellanki Sriharsha.

## Plugin assessment data
The publisher does not collect plugin-user data, assessment inputs, repository contents, prompts, reports or usage analytics through EVOLVE. The skills-only plugin has no publisher-operated backend, MCP server, telemetry or analytics. Its bundled Python scoring scripts do not make network calls. The publisher therefore has no plugin assessment data to retain, sell, share or delete.

## ChatGPT and other hosts
When EVOLVE is used inside ChatGPT or another agent host, content is processed by that host and any tools the user authorizes. The host's policies and settings govern processing, retention and deletion. This notice does not claim that content stays on the user's device or that the host collects no data. Repository access and output storage depend on the host's tools and permissions.

## Public support
Support is available through [GitHub Issues](https://github.com/harsh51191/evolvable-software/issues). If you voluntarily post an issue, its contents and GitHub account information are publicly visible to maintainers and others. This public support information is distinct from automatic plugin data collection and is subject to GitHub's policies. Do not post private source code, personal information, credentials or customer data. For requests concerning content you posted, use the issue thread or GitHub's content controls; public copies may remain outside the publisher's control.

## Questions and changes
For questions about EVOLVE's privacy practices, use the repository's GitHub Issues without including sensitive information. Material changes to this plugin's data practices will be reflected in an updated notice.
